ℹ️ About Vigi-Drive

What is Vigi-Drive?

Vigi-Drive is an advanced real-time drowsiness detection system that uses computer vision and machine learning to monitor driver alertness. By analyzing facial landmarks through a webcam, the system can detect early signs of drowsiness and trigger alerts to prevent accidents.

The system continuously tracks eye closure patterns (Eye Aspect Ratio - EAR) and mouth movements (Mouth Aspect Ratio - MAR) to calculate a drowsiness probability score using a trained machine learning model.

🔧 Key Features
  • Real-time Video Monitoring: Live camera feed with drowsiness detection overlay
  • Machine Learning Detection: Trained model predicts drowsiness probability
  • Multi-metric Analysis: Combines EAR, MAR, and temporal patterns
  • Alert System: Visual and optional hardware alerts (buzzer via serial)
  • Event Logging: Comprehensive history of drowsiness events
  • Configurable Thresholds: Adjustable sensitivity for different scenarios
  • Web-based Interface: Access from any device on your network
🔬 Technical Details
Technology Stack
  • Backend: Python, Flask, OpenCV, MediaPipe
  • ML Framework: scikit-learn (Logistic Regression)
  • Frontend: HTML5, Bootstrap 5, Custom CSS/JS
  • Database: SQLite (SQLAlchemy ORM)
How It Works
  1. Face Detection: MediaPipe detects facial landmarks in real-time
  2. Feature Extraction: Calculates EAR and MAR from landmark positions
  3. ML Prediction: Features fed to trained model for drowsiness probability
  4. Alert Logic: Triggers alerts based on configurable thresholds
  5. Event Logging: Stores events in database for analysis
📊 Metrics Explained
EAR (Eye Aspect Ratio)

Ratio of eye vertical to horizontal dimensions. Lower values (≤0.22) indicate closed eyes.

MAR (Mouth Aspect Ratio)

Measures mouth opening. Higher values indicate yawning, a drowsiness indicator.

p(drowsy)

ML model confidence (0-1). Values >0.7 indicate high drowsiness probability.
